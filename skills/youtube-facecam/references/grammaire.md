# Grammaire du montage (tirée de la vidéo d'inspiration, adaptée à la charte de l'utilisateur)

## Les 10 règles (par ordre d'importance)
1. **Light leak de 0,4 s** à chaque changement de section et pour entrer / sortir d'un plein écran : traînée bleue depuis la droite (0,12 s) → voile blanc rosé (pic = coupe) → bleu sur le nouveau plan → **grain lime** en haut à gauche qui s'efface (0,3 s). Environ 1 toutes les 15 s ; le reste en coupe sèche.
2. **Zoom arrière d'atterrissage** à chaque retour sur la face cam : ×1,25 → ×1 en 0,85 s, `expo.out`, flou 4 px → 0. **Jamais de zoom lent continu** sur la face cam.
3. **Angles en coupe sèche** à chaque coupe d'origine : large `W`, moyen `M`, serré `C`, très serré `X`, et `R` / `R2` (visage à droite, 40 % de vide à gauche pour le texte). Paliers M → C → X sur les répétitions (« très très très »).
4. **Un habillage la moitié du temps** ; jamais plus de 20–25 s de face cam nue ; les 2 premières minutes plus denses.
5. **Chaque idée devient un objet qui bouge** (cartes 3D, panneaux, interface recréée, jauge) avec un mouvement de caméra continu ; rien de figé.
6. **Texte : mots-clés seulement, mot par mot, flou 9 px → 0 et gris → blanc** (0,38 s) calé sur la voix. Petits corps, légère lueur, italique 300 pour les sous-textes. Pas de sous-titres.
7. **Les incrustations ne couvrent jamais le visage** : panneau bas sur le plan large, colonne gauche sur `R`, cartes à droite ou en haut sur l'écran. Elles restent à travers les coupes de caméra.
8. **Palette stricte** : noir, blanc, gris, `#D6FC31` pour l'accent (le vert/ambre/rouge de l'inspiration sont remplacés par lime / blanc / gris).
9. **Gabarits récurrents** : chapitre (grand chiffre italique métal + « CHOSE n SUR 3 » lettre par lettre + titre + carte 3D qui se révèle + piste de progression lime), citation (texte centré incliné de −2°, guillemets lime qui glissent, dérive 1 → 1,05), cartes de verre empilées, panneau bas, comparaison « au lieu de / je préfère » avec glissement latéral de caméra.
10. **Révélations jouées** : astérisques → texte (`scramble`), icône floue → nette par paliers, curseur qui clique, barre de prompt qui se tape puis « Skill installé ».

## Correspondance voix → bloc (film « 3 choses »)
| Moment de la voix | Bloc |
|---|---|
| Accroche | titre **centré** en bas sur la face cam, voile bas, mots flous → nets, zoom d'atterrissage à 0 s |
| « tout le monde parle de… » | B-roll cinémascope (bandes noires 2,39:1) de ses rendus, ~1 s par plan |
| Phrase forte | citation plein écran |
| « les 3 choses » | 3 cartes 3D masquées (« Chose n°1 » + ********), révélées ensuite dans chaque chapitre |
| « La 1re / 2e / 3e chose » | chapitre + film burn + light leak |
| Exemple d'usage | interface recréée (chat, barre de prompt tapée, envoi) |
| Écran avec sa voix | recadrage + zoom à chaque coupe, travelling lent, flou de profondeur léger sur les bords, carte de verre « Skill n°1 / Remotion »… en haut à gauche |
| « copier le lien et le donner à Claude » | barre de prompt « Installe ce skill : github.com/… » (URL réelle lue à l'écran), clic, jauge, « Skill installé » |
| Énumération | cartes de verre qui naissent d'un trait, une par mot |
| « ça ne marche pas comme ça » | citation plein écran |
| Écran statique pendant une explication | écran flouté + assombri, citation / cartes par-dessus, puis retour net |
| « Si tu n'as pas… » | panneau bas avec 3 ✕ qui basculent |
| Milieu de vidéo | CTA S'abonner → Abonné, cloche lime qui sonne, Partager (curseur qui clique) |
| Fin | carte commentaire en verre à droite, face décalée (`L`), « Claude Opus 5.5 » tapé, bouton lime, « Je t'envoie le guide gratuitement » |

## Son
Nappe musicale constante 20 LU sous la voix. Sous chaque leak : whoosh doux + souffle grave. Ticks / plucks très bas sur les cartes, clavier pendant les frappes, clics sur les CTA, bip doux sur les ✕, impact feutré + whoosh « cinéma » sur les chapitres.
